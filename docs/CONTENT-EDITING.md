# Content Editing Guide

Content is validated at build time. A malformed field, duplicate route, or broken internal link fails `npm run validate` before it can reach production.

## Where content lives

| Collection | Location | Format | Primary fields |
|---|---|---|---|
| Services | `src/content/services/` | YAML | `title`, `slug`, `order`, `summary`, `thesis`, six `workstreams`, `metrics`, `relatedPaths` |
| People | `src/content/people/` | Markdown | `name`, `role`, `tier`, `order`, `image`, `alt`; biography in the body |
| Clients/projects | `src/content/clients/` | Markdown | `name`, `slug`, `route`, `category`, `tier`, `logo`, `legacyUrl`; profile in the body |
| Posts | `src/content/posts/` | Markdown | `title`, `slug`, `route`, dates, `author`, `categories`, `featuredMedia`, `draft`; article in the body |
| Legacy pages | `src/content/legacy-pages/` | Markdown | `title`, `slug`, `route`, `description`, `originalUrl`, `updatedDate`; page copy in the body |

Category and author archives are migration-managed. The four mockup-led services and nine team profiles are maintained manually; WordPress-derived clients, posts, and legacy pages are generated by the migration script.

## Service example

```yaml
title: Example Service
slug: example-service
order: 5
eyebrow: What We Do
summary: A concise approved summary.
thesisLabel: Why This Matters
thesis: Approved narrative copy.
workstreams:
  - title: First workstream
    description: What this workstream covers.
# Exactly six workstreams are required.
metrics:
  - value: 5–10%
    label: A sourced, approved result range
# At least three metrics are required.
metricsNote: State the scope and source limitation.
relatedPaths:
  - /approach/
```

## Post example

```markdown
---
title: Example Post
slug: example-post
route: /example-post/
excerpt: A factual summary drawn from the article.
publishedDate: 2026-08-25T09:00:00
updatedDate: 2026-08-25T09:00:00
author: author-slug
categories:
  - category-slug
featuredMedia: /wp-content/uploads/2026/08/example.jpg
canonicalUrl: https://storesconsulting.com/example-post/
draft: true
sourceId: 99999
---

Article copy starts here.
```

## Images and links

- New approved assets go in `public/assets/` with descriptive lowercase filenames.
- Migrated WordPress assets stay at their original `/wp-content/uploads/...` path.
- Use root-relative internal links such as `/approach/`.
- Include the trailing slash on page routes.
- Do not use inline scripts, event handlers, layout HTML, or fake `#` links.

## Validation and review

```bash
npm ci
npm run validate
```

For structural changes, also run `npm run test:e2e`. Review the Vercel preview at 320, 390, 768, 1024, and 1440 pixels before approval.
